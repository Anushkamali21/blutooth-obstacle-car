# Bluetooth Obstacle Avoiding Car

## 🚀 About the Project
This project is a Bluetooth controlled robotic car that can detect and avoid obstacles using an ultrasonic sensor. It is built using Arduino and basic electronic components.

## 💡 Problem Statement
Manual robotic cars often collide with obstacles in small or crowded environments. This project aims to reduce collision risk by integrating obstacle detection with ultrasonic sensors.

## 🛠 Components Used
- Arduino Uno
- Ultrasonic Sensor (HC-SR04)
- Bluetooth Module (HC-05)
- Motor Driver
- DC Motors
- Chassis

## ⚙️ Working Principle
The ultrasonic sensor continuously measures distance. When an obstacle is detected within a certain range, the car automatically stops or changes direction.
